## 1. 文档体系概述

本文档索引列出了 CFD-Class 项目的全部技术文档，按照 GB/T 8567-2006 标准进行组织。所有文档采用统一的编号体系 `CFD-CLASS-XXX-NNN`，便于检索和管理。

### 文档编号规则

| 编号段 | 含义 | 示例 |
|--------|------|------|
| `CFD-CLASS` | 项目代号 | 固定前缀 |
| `XXX` | 文档类别代码 | SRS/SDD/UM/TP 等 |
| `NNN` | 序列号 | 001/002/003 |

### 文档类别代码对照表

| 代码 | 类别 | 说明 |
|------|------|------|
| SRS | 需求规格 | Software Requirements Specification |
| SDD | 概要设计 | Software Design Description |

| QS | 快速入门 | Quick Start |
| TG | 理论指南 | Theory Guide |

| TR | 测试报告 | Test Report |

## 5. 文档维护

### 5.1 更新流程

1. 修改对应文档内容
2. 更新文档版本号（遵循语义化版本）
3. 在文档版本历史中记录变更
4. 更新本文档索引（如新增文档）
5. 提交 PR 并通过审核
