## 2. 软件启动与关闭

### 2.1 启动软件

#### 本地启动

```bash
# 进入项目目录
cd cfd_class

# 激活虚拟环境（Windows）
.venv\Scripts\activate

# 激活虚拟环境（Linux/macOS）
source .venv/bin/activate

# 启动应用
streamlit run src/frontend/app.py
```

#### Docker 启动

```bash
docker start cfd-class-app
```

### 2.2 访问软件

启动成功后，在浏览器中访问：
- 本地访问：`http://localhost:8501`
- 网络访问：`http://<主机IP>:8501`

### 2.3 关闭软件

#### 正常关闭

在运行 Streamlit 的终端窗口中按 `Ctrl + C` 组合键。

#### Docker 关闭

```bash
docker stop cfd-class-app
```

## 4. 功能操作

### 4.1 首页操作

#### 4.1.1 浏览理论背景

1. 点击左侧导航栏"🏠 首页"
2. 向下滚动查看物理问题描述
3. 点击展开器查看详细推导过程

#### 4.1.2 查看格式对比表

在首页中部找到"六种格式对比表"，包含：
- 格式名称
- 精度阶数
- TVD 稳定性
- 适用场景
- 优缺点分析

#### 4.1.3 使用学习路径

点击"5步推荐学习路径"中的各步骤，可快速跳转到对应页面。

### 4.2 模拟页面操作

#### 4.2.1 设置物理参数

| 参数 | 操作方式 | 默认值 | 范围 |
|------|----------|--------|------|
| 左侧水深 h_L | 滑块或数字输入 | 1.0 m | [0.1, 10.0] |
| 右侧水深 h_R | 滑块或数字输入 | 0.0 m | [0.0, 10.0] |
| 左侧流速 u_L | 滑块或数字输入 | 0.0 m/s | [-5.0, 5.0] |
| 右侧流速 u_R | 滑块或数字输入 | 0.0 m/s | [-5.0, 5.0] |
| 重力加速度 g | 滑块或数字输入 | 9.81 m/s² | [0.1, 20.0] |

#### 4.2.2 设置数值参数

| 参数 | 操作方式 | 默认值 | 范围 |
|------|----------|--------|------|
| CFL 数 | 滑块或数字输入 | 0.9 | [0.1, 0.95] |
| 网格数 nx | 滑块或数字输入 | 200 | [50, 2000] |
| 终止时间 t_end | 滑块或数字输入 | 0.5 s | [0.1, 10.0] |

#### 4.2.3 选择数值格式

在"格式选择"区域勾选需要运行的格式：
- [x] Lax-Friedrichs
- [x] Lax-Wendroff
- [x] MacCormack
- [x] Godunov
- [x] HLL
- [x] MUSCL-Hancock

**注意**：至少选择一种格式。

#### 4.2.4 加载预设案例

1. 点击"预设案例"下拉框
2. 选择以下任一案例：
   - 干底 Ritter 解
   - 湿底一般解
   - 高 Froude 数
   - 对称扩展
   - 极端干湿
   - 反向流动
   - 小扰动
3. 参数将自动填充为对应值

#### 4.2.5 运行模拟

1. 确认参数设置正确
2. 确认已选择至少一种格式
3. 点击蓝色的"▶ 开始模拟"按钮
4. 等待进度条完成

#### 4.2.6 查看结果

模拟完成后，在右侧结果区查看：
- **水深剖面图**：h(x) 曲线对比
- **速度剖面图**：u(x) 曲线对比
- **误差统计表**：L1/L2/L∞ 范数
- **精确解关键量**：波速、星区状态

#### 4.2.7 导出结果

- **导出图片**：点击图表下方的"下载图片"按钮
- **导出数据**：点击误差表格下方的"下载 CSV"按钮

### 4.3 动画页面操作

#### 4.3.1 选择动画类型

| 动画类型 | 描述 |
|----------|------|
| 单格式演化 | 选定一种格式的 h(x) 随时间变化 |
| 六格式对比 | 6 个子图同步演化对比 |
| 参数扫描 | 连续变化某一参数观察影响 |

#### 4.3.2 设置动画参数

| 参数 | 操作方式 | 默认值 | 范围 |
|------|----------|--------|------|
| 帧率 (FPS) | 滑块 | 15 | [5, 30] |
| 帧数 | 滑块 | 50 | [20, 200] |
| 分辨率 (DPI) | 滑块 | 150 | [100, 300] |

#### 4.3.3 生成动画

1. 选择动画类型和格式
2. 调整动画参数
3. 点击"🎬 生成动画"按钮
4. 等待生成完成
5. 在预览区查看动画效果

#### 4.3.4 下载动画

点击"⬇ 下载 GIF"按钮，将动画保存到本地。

### 4.4 报告页面操作

#### 4.4.1 配置报告

| 配置项 | 选项 |
|--------|------|
| 报告模板 | 简明版 / 详细版 / 学术版 |
| 网格序列 | nx = [50, 100, 200, 400, 800] |
| 格式选择 | 勾选需要包含的格式 |

#### 4.4.2 生成报告

1. 选择报告模板类型
2. 确认网格序列
3. 选择需要包含的格式
4. 点击"📝 生成报告"按钮
5. 等待生成完成（通常 10-30 秒）

#### 4.4.3 下载报告

点击"⬇ 下载 HTML 报告"按钮，保存单文件自包含 HTML 报告。

## 6. 异常处理

### 6.1 常见操作异常

| 异常现象 | 原因 | 处理方法 |
|----------|------|----------|
| 参数校验错误 | 输入值超出允许范围 | 根据提示调整参数到合理范围 |
| 模拟运行失败 | CFL 过大或网格过粗 | 降低 CFL 数或增加网格数 |
| 动画生成失败 | 内存不足或帧数过多 | 减少帧数或降低分辨率 |
| 报告生成超时 | 计算量过大 | 选择简明版模板或减少网格序列 |
| 结果不显示 | 浏览器缓存问题 | 刷新页面或清除缓存 |

### 6.2 紧急处理

如遇软件无响应：
1. 刷新浏览器页面（F5）
2. 如仍无响应，返回终端按 `Ctrl + C` 停止服务
3. 重新启动软件
