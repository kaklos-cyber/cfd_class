| 序号 | 问题描述 | 严重程度 | 位置 | 影响 | 建议修复方案 |

- 位置1：`base_scheme.py:51` (`F1 = hu * u + 0.5 * g * h * h`)

- 影响：不影响测试通过，但可能导致数值不稳定
- 建议：由后端开发人员在MacCormack格式中添加数值稳定性处理
