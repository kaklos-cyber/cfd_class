### 问题 3：CI 配置存在逻辑错误（High）

**责任人**: @FE (@LSS-2004) / @PM（需确认权限）

**问题描述**:
在 `.github/workflows/ci.yml` 中发现依赖关系错误：

```yaml
# 错误 1：deploy-docs job 引用了不存在的 lint job
deploy-docs:
  needs: [test, lint]  # ❌ lint job 不存在！

# 正确应该是：
deploy-docs:
  needs: [test, security, frontend-test]
```

**实际存在的 jobs**:
- test ✅
- security ✅
- lint ❌ (不存在)
- frontend-test ✅ (新增的)
- build ✅

**影响**:
- CI pipeline 无法正常执行
- deploy-docs job 会永远处于 pending 状态
- 文档自动部署功能失效

**修复方案**:
```yaml
deploy-docs:
  needs: [test, security, frontend-test]  # 修正依赖
  runs-on: ubuntu-lest
  if: github.ref == 'refs/heads/main'
  ...
```

### 问题 4：Python 版本不一致（Medium）

**责任人**: @FE (@LSS-2004)

**问题描述**:
CI 配置中的 Python 版本不一致：

```yaml
# 全局环境变量
env:
  PYTHON_VERSION: "3.10"  # ✅ 项目要求

# frontend-test job
frontend-test:
  - uses: actions/setup-python@v5
    with:
      python-version: '3.11'  # ❌ 应该是 3.10！

# deploy-docs job
deploy-docs:
  - uses: actions/setup-python@v5
    with:
      python-version: '3.11'  # ❌ 应该是 3.10！
```

**影响**:
- 测试环境与开发环境不一致
- 可能导致 Python 3.11 特有语法在其他环境中报错
- 违反项目一致性原则

**修复方案**:
统一使用 `${{ env.PYTHON_VERSION }}` 或硬编码 `'3.10'`
