## 🔴 第二部分：发现的问题

### 问题 1（严重）：接口契约与设计文档不一致（Critical）

**责任人**: @QA 和 @BE（共同责任）

**问题描述**:

测试代码中假设了 `DamBreakConfig` 的以下接口：

```python
# 测试中使用的构造函数签名
cfg = self.DamBreakConfig(
    h_L=2.5, h_R=1.0, u_L=1.0, u_R=-0.5,
    g=9.8, cfl=0.5, nx=100, t_end=1.0,
    x_min=-10.0, x_max=10.0
)
```

但根据 [Issue #5](https://github.com/kaklos-cyber/cfd_class/issues/5) 的任务描述和第1版审核报告中的建议，`DamBreakConfig` 应该使用不同的字段命名：

```python
# Issue #5 定义的原始字段
class DamBreakConfig:
    def __init__(self):
        self.domain_length = 1000.0   # 计算域长度 [m]
        self.nx = 100                 # 网格数量
        self.g = 9.81                 # 重力加速度 [m/s²]
        self.x_dam = 500.0            # 大坝位置 [m]
        self.h_l = 10.0               # 左侧水深 [m]  ← 注意大小写！
        self.h_r = 1.0                # 右侧水深 [m]
        self.cfl = 0.9                # CFL 数
        self.t_end = 50.0             # 结束时间 [s]
        self.boundary_type = "transmissive"
```

**具体不一致之处**:

| 测试代码假设 | Issue #5 定义 | 差异 |
|-------------|--------------|------|
| `h_L`, `h_R`（大写 L/R） | `h_l`, `h_r`（小写 l/r） | ❌ 大小写不一致 |
| `u_L`, `u_R`（速度） | 未定义速度字段 | ❌ 多余字段？ |
| `x_min`, `x_max` | `domain_length`, `x_dam` | ❌ 完全不同 |
| `nx`, `t_end`, `g`, `cfl` | 相同字段 | ✅ 一致 |

**影响**:
- 如果 @BE 按照 Issue #5 实现 `DamBreakConfig`，QA 的所有测试都会失败
- 导致重复修改工作，浪费团队时间
- 违反"接口契约优先"原则

**修复方案**:

**方案 A（推荐）: QA 修改测试代码以匹配 Issue #5**
- 责任人：@QA
- 工作量：中等（需要修改 ~15 个测试文件的构造函数调用）
- 优点：保持与需求一致

**方案 B: BE 按照测试代码的接口实现**
- 责任人：@BE
- 工作量：小（只需按测试接口实现）
- 优点：测试立即可用
- 缺点：可能与原始需求不符

**建议**: 召开 @QA + @BE + @PM 的快速同步会议，确定统一的接口契约，然后更新 Issue #5 的验收标准。

### 问题 2（中等）：测试代码存在大量重复（Medium）

**责任人**: @QA

**问题描述**:

`_make_initial_state()` 方法在 **5 个测试文件**中被重复定义：

```python
# 出现位置：
tests/unit/test_schemes.py              # 第 66-76 行
tests/integration/test_dam_break_flow.py  # 第 40-50 行
tests/performance/test_performance.py     # 第 28-38 行
tests/regression/test_regression.py       # 第 26-36 行
tests/unit/test_error_analysis.py         # （可能也有）
```

**完全相同的代码**:
```python
def _make_initial_state(self, cfg):
    nx = cfg.nx
    U0 = np.zeros((2, nx), dtype=np.float64)
    x_grid = cfg.x_grid
    mid = (cfg.x_min + cfg.x_max) / 2
    left_mask = x_grid <= mid
    U0[0, left_mask] = cfg.h_L
    U0[0, ~left_mask] = cfg.h_R
    U0[1, left_mask] = cfg.h_L * cfg.u_L
    U0[1, ~left_mask] = cfg.h_R * cfg.u_R
    return U0
```

**违反原则**: DRY (Don't Repeat Yourself)

**修复方案**:
将 `_make_initial_state()` 移到 `conftest.py` 作为共享 fixture 或辅助函数：

```python
# conftest.py 新增
def make_dam_break_initial_state(cfg):
    """生成标准溃坝问题的初始守恒变量."""
    nx = cfg.nx
    U0 = np.zeros((2, nx), dtype=np.float64)
    x_grid = cfg.x_grid
    mid = (cfg.x_min + cfg.x_max) / 2
    left_mask = x_grid <= mid
    U0[0, left_mask] = cfg.h_L
    U0[0, ~left_mask] = cfg.h_R
    U0[1, left_mask] = cfg.h_L * cfg.u_L
    U0[1, ~left_mask] = cfg.h_R * cfg.u_R
    return U0
```
