### 1.2 BaseScheme 抽象基类 (B4) - ⭐⭐⭐⭐⭐ **设计优秀**

**文件**: `src/core/schemes/base_scheme.py` (236 行)

#### ✅ 架构亮点

```python
class BaseScheme(ABC):
    """Template Method 模式实现"""
    
    def __init__(self, name: str, order: int, g: float = 9.81):
        self.name = name
        self.order = order
        self.g = g
    
    @abstractmethod
    def compute_flux(self, h, u): ...
    
    @abstractmethod
    def compute_time_step(self, h, u, cfl, dx): ...
    
    def advance(self, h, u, dt, dx): ...      # Template method
    def run_simulation(self, ...): ...          # 完整模拟循环
```

**优点**:
1. ✅ 使用 Template Method 模式，结构清晰
2. ✅ 有 `SimulationResult` 类封装结果
3. ✅ 支持 progress_callback 和 snapshot_times
4. ✅ 正性保持（positivity preservation）
5. ✅ 边界条件处理（transmissive）
