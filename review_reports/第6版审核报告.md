### 2.3 🔴 **[严重] BUG：config.x 属性不存在**

**发现位置：**
- [lax_friedrichs.py:21](src/core/schemes/lax_friedrichs.py#L21)：`nx = config.x`
- [lax_wendroff.py:21](src/core/schemes/lax_wendroff.py#L21)：`nx = config.x`

**问题描述：**

两处将原来的 `config.nx` 错误地改为了 `config.x`。但查看 [`DamBreakConfig`](src/core/config.py) 类定义：

```python
@dataclass(frozen=True)
class DamBreakConfig:
    nx: int = 200          # ← 存在
    x_min: float = -5.0    # ← 存在
    x_max: float = 5.0     # ← 存在

    @property
    def dx(self) -> float: ...      # ← 存在
    @property
    def x_grid(self) -> NDArray: ... # ← 存在
    # ❌ 没有 `x` 属性！
```

**后果：** 运行Lax-Friedrichs或Lax-Wendroff格式时将直接抛出：
```
AttributeError: 'DamBreakConfig' object has no attribute 'x'
```

**影响范围：** 6种格式中有2种受影响（1/3的功能受损）

**对比其他scheme文件（均正确使用config.nx）：**
- godunov.py: `nx = config.nx` ✅
- hll.py: `nx = config.nx` ✅
- maccormack.py: `nx = config.nx` ✅
- muscl_hancock.py: `nx = config.nx` ✅

**责任人：@FE**（此处在rename commit中引入的错误）

**修复方案：** 将 `config.x` 改回 `config.nx`

```python
# lax_friedrichs.py 第21行 和 lax_wendroff.py 第21行
# 错误: nx = config.x
# 正确: nx = config.nx
```
