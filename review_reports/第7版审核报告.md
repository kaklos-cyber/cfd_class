### 2.3 🔴🔴🔴 **[致命] 核心计算被替换为Mock假数据**

**这是本PR最严重的问题，必须立即指出。**

#### 问题现象

PR #34 将所有页面的**真实后端计算**（调用 `scheme.evolve(config)`）**全部替换为了使用 numpy 随机函数生成的假数据**。涉及以下6处：

##### (1) `simulation_engine.py` — 新增 `_fallback_simulation()` 方法
```python
# 原来：调用真实的 scheme.evolve(config)
scheme = get_scheme(scheme_name)
result = scheme.evolve(self.config)

# 现在：用 tanh + random.normal 生成假数据
h = h_r + (h_l - h_r) * (
    0.5 * (1 + np.tanh((domain_length/2 - x) / sigma)) * peak_factor +
    0.2 * np.exp(-((x - domain_length/2)**2) / (2 * sigma**2))
)
if "Lax-Friedrichs" in scheme_name:
    h += np.random.normal(0, 0.05, len(x)) * h * 0.05  # 5%噪声
elif "Godunov" in scheme_name:
    h = np.maximum(h_r * 0.9, h)  # 直接裁剪
```

##### (2) `comparison_engine.py` — `run_comparison()` 同样替换
##### (3) `1_Simulation.py` — 新增 `generate_simulation_data()` 函数
##### (4) `2_Comparison.py` — 新增 `generate_comparison_data()` 函数
##### (5) `animation.py` — 新增 `generate_animation_data()` 函数
##### (6) `report.py` — 新增 `generate_report_data()` 函数

#### 各"格式"的区别仅在于噪声水平

| 格式名称 | Mock数据的区别方式 | 物理意义？ |
|---------|-------------------|-----------|
| Lax-Friedrichs | +5% 高斯随机噪声 | ❌ 无物理依据 |
| Lax-Wendroff | +3% 高斯随机噪声 | ❌ 无物理依据 |
| MacCormack | +2% 高斯随机噪声 | ❌ 无物理依据 |
| Godunov | 裁剪到 h_r×0.9 | ❌ 无物理依据 |
| HLL | 裁剪到 h_r×0.85 | ❌ 无物理依据 |
| MUSCL-Hancock | +1% 高斯随机噪声 | ❌ 无物理依据 |

#### 后果分析

| 影响维度 | 具体后果 | 严重程度 |
|---------|---------|---------|
| **教学目的** | 学生看到的不是真正的CFD计算结果，而是随机数生成的假图 | 🔴 致命 |
| **格式对比** | 不同格式的"差异"只是噪声大小不同，不代表真实精度差异 | 🔴 致命 |
| **误差分析** | L1/L2/Linf误差是数据与自身均值的偏差，毫无意义 | 🔴 致命 |
| **精确解对比** | Exact Riemann Solver被完全移除 | 🔴 严重 |
| **产品可信度** | 作为"计算流体力学教学软件"，展示虚假计算结果属于学术不端风险 | 🔴 致命 |

#### 正确的做法应该是

1. **恢复真实后端调用**：让前端正确调用后端已实现的 `DamBreakConfig` 和 `scheme.evolve()`
2. **如果确实需要Demo模式**：保留但必须明确标注"⚠️ DEMO DATA - 非真实计算"，且默认使用真实计算
