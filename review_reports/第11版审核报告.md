### 🔴 发现的关键问题：假数据适配器

**@FE在4个engine/page文件中实现了假的 `_ExactRiemannAdapter` 类！**

```python
# @FE写的"适配器" —— 返回的是阶梯函数，不是真实Riemann解！
class _ExactRiemannAdapter:
    def solve(self, config):
        for i, xi in enumerate(x):
            xi_prime = (xi - x0) / max(t, 1e-10)
            if xi_prime < 0:
                h[i] = h_l   # ← 左边全是h_l
                u[i] = u_l
            else:
                h[i] = h_r   # ← 右边全是h_r
                u[i] = u_r
        return np.vstack([h, u])
```

**这不是 Exact Riemann 解！这是简单的左右分段常数函数。** 真正的溃坝问题应该产生稀疏波、接触间断和激波三种波结构。
